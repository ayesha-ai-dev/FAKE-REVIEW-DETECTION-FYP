# FAKE-REVIEW-DETECTION-FYP
My final-year project was a Fake Review Detection System using machine learning and NLP to classify online reviews as genuine or fake. I developed a JavaScript browser extension integrated with a Flask API to display predictions, gaining practical experience in AI and web development.

# Fake Review Detection System

This project detects whether online reviews are genuine or fake.

## Technologies Used

- Python
- Scikit-learn
- NLTK
- Pandas
- Flask
- JavaScript
- HTML
- CSS

## Machine Learning Models

- Logistic Regression
- Support Vector Machine (SVM)

## Features

- Processes online review text
- Predicts whether a review is fake or genuine
- Provides results through a Flask web application
- Includes a browser extension for supported websites
